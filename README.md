Build Instructions:
1. API setup
Requirements:
- SQL Database
-    Url link
-    User login text string
- Mail transfer protocol (ex: SMTP)
-   Domain name/IP address (Host)
-   Port number
-   Admin email
View 'Run Instructions' below for implementation instructions

2. Clone repository
In a terminal, run the following command:
```bash
git clone https://github.com
cd UofC_SENG_300_F26_AS1
```
If done correctly, a local repository will be created containing the Java files from UofC_SENG_300_F26_AS1

3. Compile package
In a terminal, run the command associated with your Java build type:
Maven:
```bash
mvn clean package
```
Gradle:
```bash
./gradlew clean build
```
If done correctly, all java source code will be compiled as a .jar file
